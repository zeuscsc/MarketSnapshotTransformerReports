Positional Encoding

Transformers process tokens in parallel, losing the notion of order. Positional Encoding injects information about the token's location in the sequence by adding a fixed vector to the input embedding.

The Formula:

PE(pos, 2i) = sin(pos / 100002i/d)
PE(pos, 2i+1) = cos(pos / 100002i/d)
pytorch_implementation.py 
import torch
import torch.nn as nn
import math

class PositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000):
        super().__init__()
        
        # Create a matrix of shape [max_len, d_model]
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)
        div_term = torch.exp(torch.arange(0, d_model, 2).float() * (-math.log(10000.0) / d_model))
        
        # Apply sine to even indices
        pe[:, 0::2] = torch.sin(position * div_term)
        # Apply cosine to odd indices
        pe[:, 1::2] = torch.cos(position * div_term)
        
        # Register as buffer (not a learnable parameter)
        self.register_buffer('pe', pe.unsqueeze(0))

    def forward(self, x):
        # x shape: [batch_size, seq_len, d_model]
        # Add PE to input embeddings
        return x + self.pe[:, :x.size(1), :]

lightbulb Global Convolution

Unlike standard convolutions which are local, Spectral Convolutions operate globally. By multiplying in the frequency domain, we perform a global convolution over the entire domain in one step. The "Modes Kept" slider simulates truncating high-frequency noise, a key feature of Fourier Neural Operators (FNO).

SpectralConvBlock (Fourier Layer)

The core of the Fourier Neural Operator (FNO). It learns resolution-independent features by transforming the input to the frequency domain (FFT), multiplying by learnable weights, and transforming back (IFFT).

The Operation:

y = IFFT( R · FFT(x) ) + Wx R: Learnable Complex Weights (in Freq Domain) | W: Linear Skip
fno_block.py 
import torch
import torch.nn as nn

class SpectralConv1d(nn.Module):
    def __init__(self, in_channels, out_channels, modes):
        super().__init__()
        self.in_channels = in_channels
        self.out_channels = out_channels
        self.modes = modes  # Number of Fourier modes to multiply

        # Learnable complex weights
        self.weights = nn.Parameter(
            torch.rand(in_channels, out_channels, modes, dtype=torch.cfloat) / (in_channels * out_channels)
        )

    def complex_mul1d(self, input, weights):
        # (batch, in_channel, x), (in_channel, out_channel, x) -> (batch, out_channel, x)
        return torch.einsum("bix,iox->box", input, weights)

    def forward(self, x):
        batchsize = x.shape[0]
        
        # 1. Compute FFT
        # rfft computes FFT for real input, output is onesided
        x_ft = torch.fft.rfft(x)

        # 2. Multiply relevant modes
        out_ft = torch.zeros(batchsize, self.out_channels, x.size(-1)//2 + 1, 
                             device=x.device, dtype=torch.cfloat)
        
        # Only multiply the lowest 'modes' frequencies
        out_ft[:, :, :self.modes] = self.complex_mul1d(
            x_ft[:, :, :self.modes], self.weights
        )

        # 3. Compute Inverse FFT
        x = torch.fft.irfft(out_ft, n=x.size(-1))
        return x

# Full Block usually includes a residual skip connection
class FNOBlock(nn.Module):
    def __init__(self, width, modes):
        super().__init__()
        self.conv = SpectralConv1d(width, width, modes)
        self.w = nn.Conv1d(width, width, 1) # Skip connection
        self.act = nn.GELU()

    def forward(self, x):
        return self.act(self.conv(x) + self.w(x))

lightbulb Why Dilations?

Standard convolutions have a linear receptive field. By adding gaps (dilation) between kernel points, the receptive field grows exponentially ($2^i$) with depth. This allows TCNs to remember very long history with few layers, without the vanishing gradients of RNNs.

TemporalConvBlock (TCN)

Used in Temporal Convolutional Networks (TCNs). It combines 1D convolutions with "Causal Padding" (no looking into the future) and "Dilations" (skipping inputs) to capture long-term dependencies efficiently.

Structure:

  • Dilated Causal Conv1d
  • Weight Norm & Chomp (remove padding from right)
  • ReLU & Dropout
  • Residual Connection (Input + Output)
tcn_block.py 
import torch
import torch.nn as nn
from torch.nn.utils import weight_norm

class Chomp1d(nn.Module):
    """Removes the extra padding from the end of the sequence to ensure causality."""
    def __init__(self, chomp_size):
        super(Chomp1d, self).__init__()
        self.chomp_size = chomp_size

    def forward(self, x):
        return x[:, :, :-self.chomp_size]

class TemporalBlock(nn.Module):
    def __init__(self, n_inputs, n_outputs, kernel_size, stride, dilation, padding, dropout=0.2):
        super(TemporalBlock, self).__init__()
        
        # Convolution 1
        self.conv1 = weight_norm(nn.Conv1d(n_inputs, n_outputs, kernel_size,
                                           stride=stride, padding=padding, dilation=dilation))
        self.chomp1 = Chomp1d(padding) # Crop right side padding
        self.relu1 = nn.ReLU()
        self.dropout1 = nn.Dropout(dropout)

        # Convolution 2
        self.conv2 = weight_norm(nn.Conv1d(n_outputs, n_outputs, kernel_size,
                                           stride=stride, padding=padding, dilation=dilation))
        self.chomp2 = Chomp1d(padding)
        self.relu2 = nn.ReLU()
        self.dropout2 = nn.Dropout(dropout)

        self.net = nn.Sequential(self.conv1, self.chomp1, self.relu1, self.dropout1,
                                 self.conv2, self.chomp2, self.relu2, self.dropout2)
        
        # Residual connection (1x1 conv if dimensions change)
        self.downsample = nn.Conv1d(n_inputs, n_outputs, 1) if n_inputs != n_outputs else None
        self.relu = nn.ReLU()

    def forward(self, x):
        out = self.net(x)
        res = x if self.downsample is None else self.downsample(x)
        return self.relu(out + res)
