# Sigmoid Gate (0 to 1)
gate = torch.sigmoid(self.fusion_gate(combined))

# Weighted Sum
fused = gate * tcn_out + (1 - gate) * fft_out
x = self.fusion_proj(combined) + fused

The Gated Fusion Mechanism

The model processes time-series data through two parallel branches. The TCN captures local trends and history, while the Spectral Block captures global frequency components. A learned sigmoid gate decides how to blend them.
